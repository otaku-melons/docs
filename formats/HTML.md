# HTML
To understand this article very recommended to read our [terms](../melon/TERMS.md#-html) before.

Allowed in Melon HTML based on HTML5 and EPUB3 specifications. It's contains of abstract elements, in which implemented verification rules and basig interaction methods.

## Elements
| **Element** | **Containing text** | **Alignable** | **Footnotable** | **Extra data** | **Note** |
|---|---|---|---|---|---|
| Paragraph | ✅ | ✅ | ✅ (only for ranobe chapters) | ❌ | Storage text with basic markup. |
| Header | ✅ | ✅ | ✅ (only for ranobe chapters) | ❌ | Header with level from 3 to 6. Levels 1 and 2 reserved for book and chapter names. |
| ImageData | ❌ | ❌ | ❌ | data-file (generated by Melon) |  |
| Blockquote | ✅ (through childrens elements) | ✅ | ❌ | ✅ | Storage other elements inside. |

## Supported tags and attributes
Melon allows only several HTML tags ant it's attributes. Also supports only `center` and `right` aligns, because of other values usually determined by content rendering systems.

### Top-level tags
This tags is main data storagers. Every HTML line must starts with this tag.

|  | **blockquote** | **img** | **p** | **h3 – h6** |
|---|---|---|---|---|
| Can contain text and styling tags | ❌️ | ❌️ | ✅ | ✅ |
| Alignable | ✅ | ❌️ | ✅ | ✅ |
| Footnotable | ❌️ | ❌️ | ✅ (only for ranobe chapters) | ✅ (only for ranobe chapters) |
| Extra data | ✅ (via `data-*` attributes) | ❌️ | ❌️ | ❌️ |
| Attributes | `data-*` (extra data such as message type) | `data-file` (generated automatically), `src`, `width`, `height` | `style` (only for text align) | `style` (only for text align) |
| Comment | Can contain only other top-level tags. | Storage image. | Storage styled text. | Storage styled header. |

## Conversion
To convert data from raw HTML into Melon elements you can create elements manually.

```Python
from melon.core.base.html.elements import Paragraph
from melon.core.base.html.enums import Align

paragraph = Paragraph("Some paragraph <b>styled</b> text.")
paragraph.set_align(Align.Right)
```

Or you can use power of [BeautifulSoup](https://pypi.org/project/beautifulsoup4) with `HyperTextParser` from Melon's SDK.

```Python
from bs4 import BeautifulSoup

from melon.sdk.html_parser import HyperTextParser

chapter_data: str = """
<div class=\"container\">
    <h1>Header</h1>
    <p>Paragraph with <u>styles</u> and <a href=\"www.example.com\">link</a>.</p>
</div>
"""
soup = BeautifulSoup(chapter_data, "html.parser")
container: Tag | None = soup.find("div")

if container:
    html_parser = HyperTextParser(pretty = True)
    elements = html_parser.parse_elements(tag, allow_footnotes = True)
    elements # (Header, Paragraph)
```
Note that `HyperTextParser` provides only surface transformation for footnotes.

## Footnotes
To create footnote in ranobe chapter content you must make tag `a` with `data-footnote="{FOOTNOTE_ID}"` attribute (unique for every footnote in chapter). In other data fields footnotes denied! Anchor can contain only `*` character, if other text was placed inside it will be replaced automatically.

```HTML
<p>Questionable paragraph<a data-footnote="bce7190e-8ecc-4f82-a00c-4d86e9e16350"></a>.</p>
```

For such element `Footnote` object must be provided.

```Python
from melon.core.base.html.elements import Paragraph
from melon.core.base.html.footnote import Footnote

chapter # Any abstract ranobe chapter.

paragraph = Paragraph("Questionable paragraph<a data-footnote=\"bce7190e-8ecc-4f82-a00c-4d86e9e16350\"></a>.")

footnote_paragraphs: tuple[Paragraph, ...] = (Paragraph("Some note."),)
footnote = Footnote(footnote_paragraphs)

paragraph.set_footnotes((footnote,)) # Accepts only sequences.
```

Or you can help `HyperTextParser` to understand you footnotes. In this case `data-footnote` must be empty logical attribute and tag `a` can contains paragraphs and images.

```Python
from melon.sdk.html_parser import HyperTextParser

from bs4 import BeautifulSoup

html_line: str = "<p>Some questionable paragraph<a data-footnote><p>This is will be a note!</p></a>.</p>"
soup = BeautifulSoup(html_line, "html.parser")
container: Tag | None = soup.find("p")

if container:
    html_parser = HyperTextParser(pretty = True)
    elements: tuple[Paragraph, ...] = html_parser.parse_paragraphs(tag, allow_footnotes = True)
    elements.footnotes # (Footnote,)
```
